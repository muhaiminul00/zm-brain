## The Problem

Every growing company loses knowledge as it grows. Decisions get made in a meeting and never written down anywhere. The same context gets re-explained in a dozen emails. A new hire asks the same ten questions a departed teammate could have answered instantly — and now nobody can. Institutional knowledge lives in people's heads, and it walks out the door with them.

The tools that exist today don't fix this. A wiki goes stale the moment someone stops maintaining it by hand. Search tools like Glean or Notion AI find documents faster — but if the knowledge was never written down, faster search still returns nothing. A chat-based AI assistant can answer a question well in the moment, but it forgets the company the second the session ends.

None of these give an organization something closer to what an individual has naturally: a memory that persists, updates itself, and can be relied on by the next person — or the next AI agent — who needs it.

## Why Now

Two things changed recently that make this solvable for the first time. AI agents can now sit inside real company workflows — not just a chat window — through emerging standards like MCP. And organizations are starting to route real work through AI systems, not only through people. That shifts both who needs organizational memory and where it has to live: it can no longer be something only a person can search for. It has to be something an AI system can be handed, directly and reliably.

## What We're Proposing

**Company Brain is a memory layer for a company.** It captures what actually happens inside an organization — decisions, commitments, conversations, completed work — and turns it into a living, structured memory the company can trust, query, and hand to both people and AI agents. Not a tool employees have to remember to open. An operating layer underneath the tools people already use, quietly keeping the company's context current everywhere it's needed.

In practice, this means five things, made explicit for the first time:

- **Capturing** what's happening across the organization
- **Remembering** it reliably, in a form that doesn't decay or go stale
- **Reasoning** over it — what's at risk, what's changing, what should happen next
- **Delivering** the right piece of memory to the right person or AI agent, at the right moment
- **Governing** all of it, so nothing untrusted gets acted on automatically

## What It's Not

- Not a wiki. Nobody has to write anything down for it to work.
- Not a search tool. Search finds a document; Company Brain hands you an answer.
- Not a chatbot with a longer memory window. It's the persistent record sitting underneath every conversation — not one more conversation to have.

## Where We Are Today

We'd rather be straightforward than oversell this. Company Brain is, right now, a fully worked-through architecture — not yet a shipped product. We've spent real time thinking rigorously about how organizational memory should be structured, how trust and provenance should work, and how AI agents should be allowed to access and act on it responsibly. That thinking is done, and we're confident in it.

What doesn't exist yet is working software in your hands. We're talking to people before we build further, because we'd rather find out now whether the problem, as we see it, is one you genuinely have — before we spend months building the wrong thing.
